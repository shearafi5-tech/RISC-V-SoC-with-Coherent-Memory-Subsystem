1. Purpose

This PRD defines what the product must do, who it is for, and what conditions define acceptance. It is
deliberately non-implementation -- the TRD and Implementation Plan cover how.

The product is an educational-grade dual-core RISC-V SoC that demonstrates shared-memory and cache-
coherence concepts through a simplified invalidation-based mechanism. It is not a production chip. It is a
proof-of-concept system that a grader can verify in simulation, in physical layout, and on FPGA hardware.

2. Background & Problem Statement

In modern multi-core systems, each processor maintains private cached copies of shared data. When one
core modifies shared data, other cores' cached copies become stale. A coherence protocol ensures all cores
observe a consistent view of memory.

Industry protocols (MESI, MOESI, directory-based snooping) are complex. This product distills the concept to
its essence: two cores, three cache states (I/S/M), and invalidation-on-write -- enough to prove the student
understands why coherence is needed and how invalidation makes updated data visible.

11. Glossary

Term           Meaning
RV32I          RISC-V 32-bit base integer ISA (no compressed, no float, no CSR).
I/S/M          Invalid / Shared / Modified -- the 3 cache coherence states.
Write-through  On write, update both cache and shared SRAM simultaneously.
Invalidation   Marking a remote cache line stale (I) so it must be refetched.
AXI4-Lite      Simplified AXI4: 5 channels, no bursts, single transaction per channel.
OpenLane       Open-source ASIC flow (Yosys + OpenROAD) for sky130.
DRC            Design Rule Check -- verifies layout against PDK rules.
LVS            Layout Versus Schematic -- verifies layout matches netlist.
